# 資産形成おじさんの一言

節約・長期投資・人生とお金について、短い言葉に出会える日本語のWebアプリです。7カテゴリーに112個の言葉を収録。スマートフォンを中心に、PCでも使えます。特定の金融商品を推奨するものではありません。

## 使い方

`index.html` をブラウザで開くだけで使えます。インストール、ビルド、サーバー、ログイン、外部APIは不要です。

- 最初に端末の日付に対応する「今日の一言」を表示します。同じ日・同じ言葉データなら再読み込みしても同じです。
- 「🎲 次の言葉」で別の言葉に切り替えます。カテゴリーを選ぶと、その中から表示します。
- 「♡ お気に入り」で保存し、「お気に入りを見る」で一覧と削除ができます。
- 「シェア」は対応端末では共有メニュー、未対応端末では文章のコピーを使います。コピーもできない場合は手動コピー用の画面を表示します。

お気に入りは端末・ブラウザごとのlocalStorageに保存されます。ブラウザのデータ削除で消え、別端末には同期しません。プライベートモードや保存制限時は保存できない場合があり、画面に案内します。ファイルを直接開いた場合の保存動作はブラウザにより異なります。公開URLでの利用をおすすめします。直接開いたファイルから公開URLへお気に入りは引き継がれません。

## 言葉を追加する方法

`quotes.js` の最後の `];` の直前に、次のような1行を追加して保存します。ファイルの文字コードはUTF-8にしてください。

```javascript
  { text: "未来のために、今日できる一歩を。", category: "人生とお金" },
```

カテゴリーは「長期投資」「節約」「浪費防止」「複利」「仕事・収入」「人生とお金」「資産形成おじさん」のいずれかを正確に入力します。末尾のカンマも付けてください。文章中の半角ダブルクォートは `\"` と書くか、日本語の「」を使います。重複する文章は避けてください。

文章そのものをお気に入りの識別に使います。登録済みの文章を変更・削除すると、そのお気に入りは一覧から消えます。データを追加・変更すると、その日の一言も変わる場合があります。

## GitHubに保存してGitHub Pagesで公開する方法

既存の `asset-simulator` には追加せず、独立した `asset-words` リポジトリを使います。

1. GitHubで `kacchan-lab/asset-words` を開きます。新しく作る場合は「New repository」で `asset-words` を作成してください。無料プランでは通常、公開（Public）リポジトリを使います。
2. 「Add file → Upload files」（空のリポジトリでは「uploading an existing file」）から、上記5ファイルをアップロードします。フォルダーごとではなく、`index.html` がリポジトリの一番上に来るようにしてください。
3. 「Commit changes」で保存します。ブランチ名が `main` になっていることを確認します。空のリポジトリでは最初の保存でブランチが作成されます。別の名前なら「Settings → Branches」などのブランチ管理画面で `main` に変更してください。
4. 「Settings → Pages」を開き、Sourceを「Deploy from a branch」にします。
5. Branchを **main**、フォルダーを **/ (root)** にして「Save」を押します。
6. 公開処理が完了したら、Pages画面に表示されるURLを開きます。通常は `https://kacchan-lab.github.io/asset-words/` です。

変更するときはGitHubで対象ファイルを編集して「Commit changes」で保存します。公開への反映には少し時間がかかる場合があります。すべての読み込みパスが相対パスなので、リポジトリ名の配下でも動きます。

## 動作確認

公開後にも、次の言葉、7カテゴリーの切り替え、お気に入りの登録・削除・再読み込み後の保持、今日の一言の保持、シェアを確認してください。スマートフォンでも文字やボタンを確認してください。

今日の一言は端末の現地日付を使い、日付の変化は次にページを開いたとき・再読み込みしたときに反映されます。
